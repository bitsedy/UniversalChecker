# Rules for templates / frontend styling and copy

- **NEVER use cylindrical bar text / floating pill badges above headings**:
  Do NOT add rounded pill badges, status cylinders, or floating pill badges (e.g., `.hero-pill`, `.hero-telemetry-badge`, `.card-badge-official` or similar cylindrical badges) above page `<h1>` or `<h2>` titles. Headings should be clean, direct, and uncluttered.
- **NEVER add top rectangular authority/info banner bars**:
  Do NOT add rectangular info/regulatory banners at the very top of the page above the navigation bar (e.g., `.sovereign-banner`). The clean navigation header must always be the top-most element.
- **Strictly use simple, friendly, easily understandable language**:
  All customer-facing text, headings, buttons, and guides must use plain, simple, everyday English that Ghanaian students, parents, and cafe attendants can easily understand at a glance. NEVER use hyper-formal, bureaucratic, or pretentious fintech jargon (e.g., avoid "Dual Architectural Pathways", "Statutory Ephemeral Processing", "Settlement Total", "Immediate Reveal & Redirect"). Use simple terms like "How It Works", "Buy a Result Checker", "Get Placement Guidance", "Pick Your Exam", "Pay with Mobile Money", "Get Your PIN Right Away", "Price per Card", "Retrieve My Voucher".
- **Design consistency**:
  High-contrast, clean modern aesthetic using Savannah Emerald (`#0F766E` / `#10B981`) accents on clean canvas (`#FFFFFF` / `#F8FAFC`) with Obsidian ink (`#0A0F1D`). Clean `Inter` font for headings and UI copy, and `JetBrains Mono` strictly for voucher codes and currency amounts.
- **Reuse established action copy**:
  Use established labels ("Retrieve My Voucher", "Buy Now", "Read Portal Instructions", "Select a Result Checker") rather than inventing new phrasing.
